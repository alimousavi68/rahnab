# HTML To Classic WordPress Conversion Rules


## هدف اصلی

هدف فقط تبدیل فایل‌های HTML به PHP نیست.

هدف ساخت یک Classic WordPress Theme واقعی است که:

- قابل توسعه باشد.
- قابل نگهداری باشد.
- استانداردهای WordPress را رعایت کند.
- برای توسعه آینده آماده باشد.


---

# اصل مهم

HTML فعلی منبع اصلی طراحی است.

در هنگام تبدیل:

حفظ کن:

- Layout
- Visual hierarchy
- Typography
- Spacing
- Responsive behavior
- Animation
- Interaction


بدون درخواست صریح من طراحی را تغییر نده.


---

# فرآیند اجباری تبدیل

تبدیل باید در این مراحل انجام شود:

مرحله ۱:
بررسی قالب HTML


مرحله ۲:
طراحی معماری WordPress


مرحله ۳:
ایجاد Theme Foundation


مرحله ۴:
تبدیل Layout ها


مرحله ۵:
Dynamic کردن محتوا


مرحله ۶:
تست


مرحله ۷:
بهینه‌سازی



هیچ مرحله‌ای را بدون بررسی رد نکن.


---

# تفکیک Component ها

قبل از تبدیل هر بخش بررسی کن:

آیا این قسمت:

- Template است؟
- Template Part است؟
- Function است؟
- Dynamic Content است؟
- Static HTML است؟


از کپی کردن HTML تکراری جلوگیری کن.
