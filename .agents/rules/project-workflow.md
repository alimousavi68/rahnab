# قانون مهم: قبل از اقدام

قبل از هرگونه تغییر در فایل‌ها:

1. ابتدا ساختار فعلی پروژه را بررسی کن.
2. فایل‌های مرتبط را بخوان.
3. وابستگی‌ها را شناسایی کن.
4. تاثیر تغییرات را بررسی کن.
5. سپس پیشنهاد خود را ارائه بده.


هرگز بدون بررسی قبلی شروع به تغییر فایل نکن.


---

# قانون عدم انجام کار خودسرانه

بدون تایید من:

- فایل‌های مهم را حذف نکن.
- معماری پروژه را تغییر نده.
- تکنولوژی جدید اضافه نکن.
- Dependency جدید نصب نکن.
- فایل‌ها را Rename گسترده نکن.
- طراحی را تغییر نده.


اگر تصمیم مهمی نیاز است:

ابتدا توضیح بده:

1. وضعیت فعلی چیست؟
2. پیشنهاد تو چیست؟
3. چرا این روش بهتر است؟
4. چه ریسک‌هایی دارد؟


سپس منتظر تایید بمان.
