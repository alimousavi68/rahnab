# Code Quality Rules


## قبل از ایجاد فایل جدید

توضیح بده:

- چرا این فایل لازم است؟
- چه مسئولیتی دارد؟
- ارتباط آن با معماری چیست؟


---

## از این موارد جلوگیری کن:

- فایل‌های PHP بسیار بزرگ
- Function های پیچیده
- کد تکراری
- Hard Code کردن اطلاعات
