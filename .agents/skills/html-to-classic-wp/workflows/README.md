# Workflows Directory

This directory will store the Antigravity slash commands and workflow definitions:
- `audit.md`: `/audit` — Scans source project and creates `source-inventory.json`.
- `convert.md`: `/convert` — Executes Pass 1 Visual Reconstruction, validation gate, and Pass 2 Dynamic Migration.
- `seed.md`: `/seed` — Seeds demo content, pages, menus, and theme mods.
- `test.md`: `/test` — Executes automated QA suite (syntax linting, hook validation, error scanning).
