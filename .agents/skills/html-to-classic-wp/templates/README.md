# Templates Directory

This directory will store parameterized starter boilerplate templates (`.tpl` files) for the `html-to-classic-wp` Skill, including:
- `classic-theme/`: Standard theme files (`style.css.tpl`, `functions.php.tpl`, `header.php.tpl`, `footer.php.tpl`, `index.php.tpl`, `front-page.php.tpl`, `page.php.tpl`, `single.php.tpl`, `archive.php.tpl`, `404.php.tpl`, and `inc/*.tpl`).
- `companion-plugin/`: Companion plugin boilerplate (`plugin-bootstrap.php.tpl`, `cpt.php.tpl`, `taxonomies.php.tpl`, `shortcodes.php.tpl`, `seed-installer.php.tpl`).
- `patterns/`: Block pattern starter headers (`pattern-header.php.tpl`).
