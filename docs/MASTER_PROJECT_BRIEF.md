### متن مصوب درباره ما و چشم‌انداز ۱۴۰۵:
- **چشم‌انداز ۱۴۰۵:** شرکت سرمایه‌گذاری ره‌ناب فارمد در راستای تبدیل شدن به بزرگترین مرکز جذب ایده‌های نوآورانه و سرمایه‌گذار در پروژه‌های دانش‌بنیان در حوزه بایوتکنولوژی تا سال ۱۴۰۵ در نظر دارد با حفظ ماهیت خصوصی و اتکا به سرمایه‌های انسانی، شایستگی‌های مدیریتی و بهره‌مندی از فناوری روز دنیا ضمن برخورداری از شاخص‌های ارزنده اقتصادی و زیست‌محیطی به نحوی مدبرانه با تدوین و پیاده‌سازی راهبردهای توسعه‌گرایانه در استفاده بهینه از فرصت‌ها، کسب مطلوبیت اقتصادی و ارتقاء سرمایه اجتماعی پیشتاز باشد.
- **مأموریت:** شرکت ره‌ناب با استفاده آگاهانه از ظرفیت‌های ملی و بین‌المللی قصد دارد در حوزه بایوتکنولوژی با جذب سرمایه‌های انسانی نخبه و شایسته، سرمایه‌گذاری بر روی ایده‌های ناب محصولات دانش‌بنیان و از رهگذر کمک به نوآوری، توسعه و شتاب‌دهی آن‌ها برای ارتقاء سلامت و کیفیت زندگی آحاد جامعه تلاش کند و برای کلیه ذی‌نفعان خلق ارزش نماید.
- **شاخص مالی/سرمایه‌گذاری:** بیش از ۲,۰۰۰ میلیارد تومان (+2K B IRR) سرمایه‌گذاری در توسعه زیست‌بوم دانش‌بنیان سلامت.

# 16. خروجی نهایی پروژه

فرآیند پروژه عمداً باید دو مرحله طراحی/توسعه داشته باشد:

### مرحله A — Prototype

ابتدا:

```text
HTML
CSS
JavaScript
```

به‌صورت یک Prototype کامل و قابل مشاهده ساخته شود.

در این مرحله هنوز WordPress وارد پروژه نمی‌شود.
منظور از css , javascript این نیست که لزوما از کتابخانه های معروفی مثل tailwind استفاده شود و به صورت pure باشد چه بسا استفاده از کتابخانه های معروف و متداول که باعث افزایش سرعت کدنویسی/ نظم و انظباط و طراحی استاندارد تر هست در اولویت هست. همین موضوع در مورد جاوا اسکریپت هم صادق است مخصوصا gspa و.. 

هدف این مرحله:

- تثبیت UX
    
- تثبیت Visual Language
    
- تست Interaction
    
- تست Responsive
    
- تست RTL/LTR
    
- تست Animation
    
- تست Information Architecture
    

### مرحله B — WordPress

پس از تأیید Prototype:

```text
HTML/CSS/JS
        ↓
Design System
        ↓
WordPress Architecture
        ↓
Custom Theme
        ↓
CMS Components
        ↓
Dynamic Content
```

قالب نهایی باید **Custom WordPress Theme** باشد، نه پوسته آماده‌ای که صرفاً شخصی‌سازی شده باشد. که این تبدیل و طراحی باید با تکیه به اسکیل و rules های ویژه ای که در پوشه با نام .agents ذخیره شده است و میتونی در زمان مناسب بهش بپردازی و ازش استفاده کنی.
